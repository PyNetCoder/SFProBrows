# Changelog

All notable changes to the **SFProBrows** project will be documented in this file.

## [1.0.0] - 2026-06-26
### Changed
* Core architecture migrated to **PySide6** for advanced UI layout and enhanced web engine performance.

---

## [0.2.0] - June 2026
### Added
* Integrated required standalone DLLs to fix environment-specific dependencies and stabilized the compiled executable environment.

---

## [0.1.3] - 2026-06-17
### Fixed
* Resolved all chronic crash issues reported in versions 0.1.0, 0.1.1, and 0.1.2 through a comprehensive code revision ("Stability Master").

### Optimized
* Streamlined dependency management.
* Optimized the `__internal` folder footprint to reduce overhead.

### Performance
* Enhanced overall browser stability and startup reliability.

---

## [0.1.2] - June 2026
### Fixed
* Investigated and patched memory leakage issues that caused random freezes and unexpected shutdowns ("Crash-Killer").

### Stability
* Improved core event handling to reduce dependency conflicts during browser launch.

---

## [0.1.1] - 2026-06-13
### Fixed
* Integrated the Registry (`.reg`) file system for official Windows default browser recognition.
* Fixed unexpected application crashes occurring during startup sequence.
* Corrected installation path mapping for `Program Files` to prevent file system errors.

### Changed
* Enhanced debugging: Traceback error logs are now visible for better error tracking.
* Switched compilation architecture to PyInstaller `onedir` (instead of `onefile`) to ensure faster dependency loading and improved stability.

---

## [0.1.0] - May 2026 (RealStart)
### Changed
* Rebranded the application name from *FSProBrows* to **SFProBrows** to avoid inappropriate meanings of the previous abbreviation.
* Transitioned the runtime into a stable, console-hidden window environment.

---

## [0.1.0] - May 2026 (Beginner)
### Added
* Started the initial development phase of the web browser.
* Merged **HackScript (HS)** and **WorldPageWeb (WPW)** into the unified **CodeProg (CP)** ecosystem.
